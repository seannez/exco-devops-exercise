
# DevOps Technical Exercise

## Plan

1. Create a minimal Node.js web service with HTML output, version and pod name.
2. Containerize the service with Docker using a non-root user.
3. Provision a local Kubernetes cluster with one control-plane and two workers using Terraform and Kind.
4. Install Argo CD and an ingress controller using Terraform.
5. Deploy the application through Argo CD using Kubernetes manifests stored in Git.
6. Configure two replicas, health probes, resource requests and limits, and Ingress.
7. Verify the application in a browser and document the results.

## Tools

- Node.js
- Docker
- Terraform
- Kind
- Kubernetes
- Argo CD
- GitHub
